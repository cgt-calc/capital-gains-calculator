# Harper lints accepted in this repository, one extended regex per line,
# matched against `harper lint --format compact` output lines.
# Use this only for words the dictionary cannot whitelist: Harper's base
# dictionary dialect-gates US spellings, so they stay flagged under
# --dialect gb even when added to .harper-dictionary.txt.

# "Equity Award Center" is Schwab's product name.
^schwab_equity_award_json\.py:.*`Center`
# NO_COLOR is a standard environment variable (https://no-color.org/).
^logging\.py:.*`COLOR`
# "a share that fell that far" is correct; the FeelFell typo rule misfires.
^schwab\.md:.*FeelFell
# "Section 106A" - Harper reads the trailing "A" as an indefinite article.
^raw\.md:.*AnA
# An example commit hash in a comment about `git describe` output.
^version\.py:.*`g3473d67`
# "a backup tag" is a compound noun; Harper reads it as the verb "back up".
^version\.py:.*PhrasalVerbAsCompoundNoun
# "A fee on the row is real money" is complete; MissingPreposition misfires.
^ingestion\.py:.*MissingPreposition
# "CR CR LF" spells out the doubled carriage return; the repeat is the point.
^util\.py:.*RepeatedWords
# "a header that does not match" is a relative clause, not a comparison.
^vanguard\.md:.*ThatThan
# "What a lot does state" - a lot here is a parcel of shares, not the
# quantifier "a lot of".
^schwab_equity_award_json\.py:.*QuantifierNeedsOf
# "every source row and its ordering" is possessive, not a contraction.
^stock_split_planning\.py:.*ItsContraction
# "the rows that preceded it are already in the units it leaves behind"
# already agrees; PronounInflectionBe reads the wrong subject.
^matching\.py:.*PronounInflectionBe
# "nothing earlier that day" is a time reference, not a comparison.
^stock_splits\.py:.*ThatThan
# "a very small holding" is a shareholding, not a smallholding.
^trading212\.md:.*CompoundNouns
# "Trading 212's timestamp" is possessive; Harper reads the digits as the
# end of a sentence and the "s" as a word of its own.
^trading212\.py:.*`s`
# The ISIN in the comment on the exchange-alias table, naming the security
# whose ticker code the sentence is about.
^const\.py:.*`US67066G1040`
# "True on every one of them" counts the rows one at a time; Harper reads it
# as the closed compound "everyone".
^model\.py:.*Everyone
# "every one of those decisions" is two words; the Everyone rule misfires.
^report_view\.py:.*Everyone
# "how many candidates there are" is correct; ThereIsAgreement expects the noun
# after the verb, but this construction puts it first.
^trading212\.py:.*ThereIsAgreement
# "Either layout of the price-only export" is a compound noun; Harper
# reads it as the verb "lay out".
^schwab\.md:.*PhrasalVerbAsCompoundNoun
